# Chandra — Cinematic Portfolio v2

A new React + Vite portfolio with a curved, tactile, dark-cinematic visual direction. Palette: black, white and red `#9b1614`.

## Run locally

1. Extract the ZIP.
2. Open the extracted `chandra-portfolio-v2` folder in VS Code.
3. In that folder's terminal run:

```bash
npm install
npm run dev
```

4. Open the local URL Vite prints (usually `http://localhost:5173`).

## Personalise it
- **Add videos:** use the upload controls in Editing, Films and Client Work. Files preview in the current browser session; they are not uploaded to a server and may need to be selected again after refresh.
- **Edit project details:** click “Edit project details” on a card.
- **Add scripts:** use “Upload a script”; current version holds previews/links in the browser session only.
- **About:** edit the intro directly and add a portrait.
- **Contact:** enter your email, Instagram and YouTube links. The contact button opens the device's email app using the email entered in the form.

## Before publishing
This is a front-end portfolio template. For permanent media uploads, contact-form delivery, and saved edits across devices, connect a backend or a media/storage service. Replace sample project titles/descriptions with your final details.
